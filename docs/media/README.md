# Catalog demo

`catalog-preview.gif` is a 12.5-second looping excerpt of the approved public-site demo, showing Trending, Browse catalog, Organizations, Developers, and MCP. It is 720×450 at 8 frames per second with a 128-color palette. Its intended use is the GitHub README, where MP4 autoplay is not dependable. GitHub and OS reduced-motion preferences may pause it.

The full 54.9-second, 2.5× H.264 recording is `frontend/public/catalog-demo.mp4`, published at https://paperswithcode-cyber.com/catalog-demo.mp4. It contains public catalog pages only. The GIF links directly to the site; a separate text link opens the full video.
