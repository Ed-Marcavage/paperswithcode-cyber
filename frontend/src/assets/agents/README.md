# Agent logos

The Claude, Codex, Cursor, and OpenCode SVGs come unmodified from [Cloudflare Docs](https://github.com/cloudflare/cloudflare-docs/tree/53c0f70457e6430d69da45c6e126383639b469f8/public/icons/agents), commit `53c0f70457e6430d69da45c6e126383639b469f8`.

Cloudflare Docs distributes these assets under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); a copy is in LICENSE.txt. Claude, Codex, Cursor, and OpenCode marks belong to their respective owners.

The Personal agents sidebar uses artwork from [OpenAI dots](https://chatgpt.com/features/dots/), [Grok Bot](https://apps.apple.com/us/app/grok-bot/id6794501026), and [Meta Muse](https://muse.ai/). The discovery build verifies those files against the SHA-256 digests in [personalAgentArtwork.ts](../../../personalAgentArtwork.ts) and embeds the images in its frontend bundle. These third-party marks retain their respective owners' rights.
